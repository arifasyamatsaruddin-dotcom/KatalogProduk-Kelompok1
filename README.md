# 🔬 SNEAKER LABS - Experimental Tech-Wear Sneaker Platform

A modern, high-performance e-commerce platform for premium tech-wear sneakers with experimental design aesthetics. Built with a monochromatic color scheme (black, white, gray) to evoke a futuristic laboratory environment.

**Live Features:** Modern minimalist UI | Real-time cart updates | Advanced filtering | Wishlist management | Responsive design

---

## 🎨 Design Concept

**Sneaker Labs** is positioned as an experimental platform for premium minimalist sneakers. The design philosophy embraces:
- **Monochromatic Palette**: Black, white, and gray tones for a tech-lab aesthetic
- **Clean Typography**: Bold, uppercase lettering for modern impact
- **Minimalist Layout**: Spacious grids and refined spacing
- **Tech-Wear Aesthetic**: Futuristic but functional design approach

## 🚀 How to Use

1. **Open Homepage**: Open `index.html` in browser
2. **Browse Products**: Click "Jelajahi Katalog" to explore
3. **Use Filters**: Narrow down by category, size, color, price
4. **Search**: Use search bar to find specific products
5. **Add to Cart**: Click product + "Tambah ke Keranjang"
6. **Wishlist**: Click heart icon to save favorites
7. **View Cart**: Click cart icon for slide-in preview
8. **Checkout**: Go to cart page for order summary
